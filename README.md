# Joshua Matthews Portfolio

Modern freelance web developer portfolio for Joshua Matthews.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages

This project is configured for GitHub Pages at:

```text
https://johua16.github.io/joshua-matthews-portfolio/
```

The deploy workflow lives in `.github/workflows/deploy.yml` and publishes the `dist` folder after every push to `main`.

In the GitHub repository settings, set Pages source to **GitHub Actions**.
